# Inactive Warm Up score assets

This directory retains the selected public Mozart card bytes and a
[written-measure map](mozart-k545-1-allegro/measure-map.json) for issue
[#88](https://github.com/thdecn/apartmender/issues/88), Bead `sludge-5l8.2`.
No application entry, timer, catalogue change or authenticated read is enabled.

The map lists exactly 23 complete measures: 1–11, 13–17, 18–20 and 22–25.
Each image is copied unchanged from the approved retained bundle, including its
existing first-sounding-onset landing per staff and preceding rests. These
written numbers are independent of the bundle's reverse export filenames.
The later passage model owns the six chronological technical choices; this
map does not create another exercise or include Chopin.

The score adaptations are CC BY-SA 3.0. Keep the adjacent
[license and attribution](mozart-k545-1-allegro/LICENSE-AND-ATTRIBUTION.md) with
the images. Full source, editable notation, reference PDFs, source-anchor and
fingering evidence, warnings, archives and reproduction runtime remain under
[`artmended/`](../../artmended/README.md). Chopin’s Prelude in E minor, Op.28 No.4
is separate repertoire, never an additional Warm Up choice.

Run `python3 -B tools/validate-warm-up-assets.py` from the repository root for
the offline checksum/archive/runtime/map gate. The
[design](../focused-practice-mvp.md) and [audit](../focused-practice-review.md)
describe the remaining dependency-gated application work.
